# Using Mendelian Randomization to decipher the prodrome of Amyotrophic Lateral Sclerosis and Parkinson's Disease

Work carried out as a research intern in computational neuroscience in the ARAMIS team at the Paris Brain Institute (ICM) in Paris, as part of an my engineering degree at the École Centrale de Lille.

## Features 

This project aims to decipher the true effects of potential risk factors for neurodegenerative diseases such as Amyotrophic Lateral Sclerosis or Parkinson’s Disease. 

The study focused on the use of Mendelian randomization, a method that allows us to use genetic variants as instrumental variables, thereby avoiding certain biases in our statistical analysis. In particular, we have analyzed the causal relationships between cardiometabolic risk factors and neurodegenerative diseases. 

By exploiting data from large genome-wide association studies, we have observed potential indications of the protective effect of type 2 diabetes on ALS in European populations, and with greater certainty, the aggravating effect of high cholesterol levels on ALS or even BMI on Parkinson’s disease.

## Running the project

All the different scripts used to make these analyses are located in the `/scripts` folder and the main file use to run all of those is `/run_analyses.ipynb` (which also contains code in R).
